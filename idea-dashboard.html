PR Creation Controls (Fixes “Can’t Create PR”)

  • AMO verifies repo permissions + branch protection before PR agent runs.
  • Template-enforced PR body (motivation, diff summary, test proof, rollback plan).
  • Auto-retry with fallback token and reviewer escalation if PR API fails.
  • Hard stop if tests are red or budget threshold breached.

Strict Token & Credit Controls (AMO Policies)

  • Per-agent token caps with automatic pause after threshold breach.
  • Model routing policy: cheap model first, premium model only with confidence trigger.
  • Daily/weekly budget windows with alerting + lock mode.
  • Mandatory eval score before allowing expensive long-context runs.
